# server-snapshot-2026-08-20

Snapshot of the code and documentation on the trading server, taken 2026-08-20.

## What is here

| Path | Contents |
|---|---|
| `trading-system/` | Bot code — segment bots, brains, supervisors, scripts |
| `research/` | Design corpus, decisions, boards, research reports |
| `crypto-bot-publish/` | Earlier publishable bot tree |
| `video-notes/` | Notes distilled from video sources |
| `fsync-bench/` | Disk fsync benchmark |
| `.claude/` | Rules, hooks, skills, plans, memory (allowlisted paths only) |

## What is deliberately excluded

- **Test files and `tests/` directories** — excluded at the user's request.
- **`~/capture/`** — runtime state, ledgers, captured market data. Data, not code.
- **Toolchain and caches** — `.venvs`, `.mamba`, `.local`, `.npm`, `.cache`, `.conda`, `snap`,
  `node_modules`, `__pycache__`, `.git` internals.
- **Everything in `~/.claude` outside the allowlist** — transcripts, plugin cache, session
  state, credentials. The config directory is admitted by allowlist, never by ignore-list.

Only source and markdown extensions were collected: `.py .md .sh .js .ts .tsx .jsx .html
.css .sql .yaml .yml .json .toml .ipynb .cfg .ini .txt`.
